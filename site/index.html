GoldED for Python

Read and write messages, automate message handling and exchange mail on active FTN networks with Python.

FidoNet is a network of bulletin-board systems (BBSes) that exchange messages. FTN means FidoNet Technology Network: a network using the same message formats and delivery conventions. GoldED is a terminal program for reading and writing those messages. These Python packages let your own programs work with the message bases and network protocols, whether you operate an active system, build a new tool or work with an existing archive.

Have an archive and just want to read it? Read a message archive → shows how to recognise the files, list messages and open their text. No Python code or network setup required.

01

Start with one local message

You need Python 3.12–3.14 on Linux or macOS. You do not need a FidoNet address, a running BBS or an existing message base to try the libraries. The first example creates a temporary message, reads it back and removes its files.

Install the packages, then follow Your first message. If you already have a message base, start with a copy and use Choose a reader to select its file format.

Prefer terminal commands to Python code? Use the CLI guide. CLI means command-line interface; the command is called ftnt.

02

From stored messages to network delivery

A message base is the set of files where a BBS stores messages. MSG, JAM, Squish and Hudson preserve existing storage formats. SQLite provides a new transactional format for netmail and echomail. Choose the package that matches your files or the base you want to build; you do not need all five formats.

Sending a message adds a few steps. A tosser sorts incoming messages into the right message base and prepares outgoing messages. A packet is a file containing messages for transfer. Binkp transfers files between systems over a network connection. A nodelist is a directory of systems and their contact information.

For example: Alice writes a message in a local message base. The tosser puts it in an outgoing packet. Binkp transfers the file to another system. Its tosser files the message so Bob can read it.

  • Packets: read or create the files used to exchange messages.
  • Nodelists: look up systems, addresses and connection details.
  • Binkp and BSO: transfer files and manage the outgoing queue. BSO is the on-disk queue layout used here.
  • Tosser operations: combine storage, sorting, routing and transfer into a configured node.

Start with local storage before configuring a network node. The network examples use invented addresses and temporary files; they do not connect you to FidoNet.

golded-ftn-nodelist

A nodelist is a directory of systems in an FTN network. It describes their addresses, operators and connection information. Use this package to read that directory and find entries; it does not connect to those systems.

Version 0.1.0 candidate. Python 3.12–3.14 on Linux and macOS.

01

Installation

Shell commands
python -m pip install golded-ftn-nodelist==0.1.0

The command becomes available after publication. For the unpublished suite, install all reviewed wheels from the candidate wheelhouse; no sibling checkouts are needed.

02

First working example

The example parses three invented directory entries and finds the operator named Bob. The data is included in the example; no downloaded nodelist is needed.

Python · RUNNABLE
from golded_ftn_nodelist import ListDialect, ParseOptions, parse_list, find_by_name

source = b"Zone,2,Example,Nowhere,Coordinator,-Unpublished-,300,CM\r\nHost,999,Example,Nowhere,Alice,-Unpublished-,300,CM\r\n,1,Example,Nowhere,Bob,-Unpublished-,300,CM\r\n"
document = parse_list(
    source,
    options=ParseOptions(
        dialect=ListDialect.STANDARD,
        domain="test.invalid",
        default_zone=2,
    ),
)
assert len(find_by_name(document, "Bob")) == 1
03

Formats and configuration

Select an explicit ListDialect: STANDARD, BOSS, POSS, POINT, DK_FAKENET or UBOSS. Supply domain and default zone; do not infer a production network from a filename. ParseOptions selects ASCII/CP850, CRC policy, explicit fakenet mappings and optional boss entries. CRC uses CRC-16/XMODEM; it detects accidental damage, not authenticity. REQUIRE_VALID rejects absent or invalid CRCs.

export_list returns bytes in SEG, PVT, NAM, NET, DUP, TXT or VR7_TEXT format. VR7_TEXT is text, not a binary V7 index. DkpcExportOptions controls encoding, headers, boss inheritance, pointnets and terminators. Preserve the input bytes separately if provenance matters; an export is not a byte-identical backup.

04

Errors and privacy

Use ListParseError, ListExportError and MappingResolutionError codes and structured diagnostics. Inspect document diagnostics before using recovered entries. Unknown or ambiguous boss mappings require explicit input; do not guess routes. Names and phone fields are personal data. Errors and repr suppress their contents; application logging must preserve that boundary. No network fetching or filesystem write occurs in the parser/exporter itself.

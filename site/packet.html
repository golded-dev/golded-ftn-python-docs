Packed messages. Explicit boundaries.

golded-ftn-packet

Version 0.1.0 candidate. Python 3.12–3.14 on Linux and macOS.

01

Installation

Shell commands
python -m pip install golded-ftn-packet==0.1.0

The command becomes available after publication. For the unpublished suite, install all reviewed wheels from the candidate wheelhouse; no sibling checkouts are needed.

02

First working example

Python · RUNNABLE
import io
from datetime import datetime
from golded_ftn import FtnAddress
from golded_ftn_packet import (
    PacketHeaderInput,
    PacketMessageInput,
    encode_message,
    write_packet,
    read_packet,
    decode_message,
)

a = FtnAddress(zone=2, net=999, node=1)
b = FtnAddress(zone=2, net=999, node=2)
message = encode_message(
    PacketMessageInput(
        from_name="Alice",
        to_name="Bob",
        subject="Demo",
        body_text="Hello.\n",
        from_address=a,
        to_address=b,
        posted_at=datetime(2026, 3, 15, 12),
    )
)
stream = io.BytesIO()
# 0x00FE is a synthetic fixture value, never a production product assignment.
write_packet(
    stream,
    header=PacketHeaderInput(
        origin=a,
        destination=b,
        created_at=datetime(2026, 3, 15, 12),
        product_id=0x00FE,
    ),
    messages=[message],
)
reader = read_packet(io.BytesIO(stream.getvalue()))
records = list(reader)
assert reader.is_complete and len(records) == 1
assert "Hello." in decode_message(records[0]).decoded_text
03

Formats and semantics

Reads bounded Type-2 and Type-2+ packets; writes Type-2+ packets. Type 2.2, fileecho and archive extraction are outside this package. Stream consumption must reach the packet terminator and physical EOF before is_complete is true. A record being yielded does not prove the remaining packet is valid.

decode_message validates date, charset and controls separately from framing. resolve_netmail_addresses reconciles INTL/FMPT/TOPT with packed addresses. encode_message canonicalizes LF, CRLF and CR to CR wire lines. It does not repair conflicting controls. write_packet requires an explicit product_id; obtain your production product assignment instead of copying fixture 0x00FE.

04

Errors and recovery

PacketParseError means framing failed: do not import a partial packet as complete. PacketSemanticError identifies an invalid record; a caller may quarantine that record only after validating the whole packet. PacketEncodeError rejects invalid outbound fields. Codes, offsets and ordinals are safe diagnostics; payloads remain private. The library does not authenticate incoming links or write message bases.

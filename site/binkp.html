Queued packets. Durable receipts.

golded-ftn-binkp

Version 0.1.0 candidate. Python 3.12–3.14 on Linux and macOS.

01

Installation

Shell commands
python -m pip install golded-ftn-binkp==0.1.0

The command becomes available after publication. For the unpublished suite, install all reviewed wheels from the candidate wheelhouse; no sibling checkouts are needed.

02

First working example

Python · RUNNABLE
from pathlib import Path
from tempfile import TemporaryDirectory
from golded_ftn import FtnAddress
from golded_ftn_binkp import BsoSpool, DomainOutboundRoot

with TemporaryDirectory() as directory:
    spool = BsoSpool(
        (
            DomainOutboundRoot(
                domain="test.invalid",
                default_zone=2,
                root_path=str(Path(directory) / "outbound"),
            ),
        )
    )
    peer = FtnAddress(zone=2, net=999, node=2, domain="test.invalid")
    with spool.lock_address(peer, timeout=1.0) as lock:
        assert spool.list_ready(peer, lock=lock) == ()
03

BSO publication and transport

DomainOutboundRoot scopes each domain and default zone. BsoSpool owns BSO zone and point layout, .bsy/.csy address locks, direct packets and flow references. Use the returned address lock for list/publish/acknowledge operations. Lock all AKAs in canonical order; a busy address is retryable, not permission to bypass locks. Publication is idempotent by job identity; acknowledge only after durable delivery. Flow actions can remove/truncate payloads, so preserve their ownership boundary.

BinkpConfig supplies local AKAs, links and private temporary, secure inbound, unauthenticated quarantine and receipt directories. BinkpLink.password is a secret configuration field. Keep it in a permission-restricted file or an in-memory configuration supplied by a secret store. Never put it in CLI arguments or logs. BinkpClient and BinkpServer are asynchronous; await their methods in your event loop. The tosser CLI wraps these with loopback-only host checks.

04

Authentication, restart and limits

Supports binkp 1.0/1.1, CRAM-MD5 authentication, receiver-generated filenames, partial staging, resume and durable InboundReceipt before M_GOT. Plaintext password fallback requires explicit permission. Authentication does not encrypt message contents. TLS and CRYPT are not implemented. This package is not an Internet-facing deployment policy or a packet semantic validator.

Keep partial files and receipts through restart; reconcile acknowledgements with your durable journal rather than blindly resending. Catch BinkpError and BsoError subclasses by code. A conflict or exhausted name space needs operator resolution; retrying with a new job identity can duplicate delivery.
